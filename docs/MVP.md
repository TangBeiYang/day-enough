# DayEnough MVP

## 已确认的目标
个人任务规划工具，回答「今天做什么、做到多少够了」。主要在两台电脑、三个系统环境使用，几乎总是联网。采用 Web + 服务端统一存储，可部署到现有阿里云 2 核 2GB Linux 服务器。名称 DayEnough，仓库 day-enough。

## 第一版范围
- 用户名和密码登录；持邀请码注册，每个账号拥有独立任务与设置。旧数据归 owner 账号。
- 服务器可发布网站公告，所有已登录账号在页面顶部查看。
- 任务名称、可选截止日期、后果严重度、剩余用时、能量等级、可选下一步；编辑、完成、暂时搁置、继续做和删除。
- 普通任务可选计划日期；周期任务每天、每周多选星期、每月指定日期/月末，支持暂停、恢复和实例历史。
- 今日时间预算和状态；推荐分配分钟数、理由、截止风险；计划固定保存。
- 跳过、完成今日份额、手动记录工作分钟、调整剩余估计、主动重排与自己安排今日任务。
- 阶段计划：日期范围、任务目标集、完成任务或投入分钟目标、到期后未完成提醒与继续追踪；主动生成/重排今日安排时参与推荐。
- 默认、每周各日和指定日期的可用时间设置；推荐先试排未来数周，再只保存今日建议。
- 按上海时区划分日期；默认可用时间设置。
- JSON 导出/恢复、SQLite 离线/在线备份说明、轻量部署说明。

## 规则约定
- 截止时间可留空；填写时 MVP 精确到日期，默认当天结束（Asia/Shanghai）。无截止日期任务不产生截止风险提示，仍可参与推荐。
- 计划完成日期表示用户希望完成的日期，不限制推荐开始时间；创建后立即进入推荐候选，按目标日期远近和剩余用时分配。普通任务可不填，不得晚于已填截止日期。周期规则的开始日期另表示生效日期。
- 周期规则与实例分离，每次独立进度；每月不存在的日期取月末。默认漏做后不补做，保留投入记录；也可选保留待办。
- 周期专用表单：每周的计划完成星期/可选截止星期，每月的计划完成几号/可选截止几号或月末。截止取计划当天或之后最近的匹配日期，可跨周/月；到截止日结束才算漏做，未设截止时以实例所属日/周/月结束为界，超过计划完成日不立即标记漏做。
- 打开/刷新或操作时提前生成当前日/周/月内的实例，完成本期不提前生成下一期，不使用定时服务；暂停期间不生成，恢复不回填。修改规则只影响未生成实例，已有实例单独编辑。
- 周期任务尝试安排本次全部剩余时间，但仍受时间/精力预算限制；新实例不自动塞入已有计划，需主动重排。
- 任务总览默认显示进行中的普通任务、当前周期及保留待办的周期实例、重复规则；本次实例和重复规则分别编辑。
- 删除任务会清除相关投入和每日安排记录，需输入确认；删除周期本次会阻止它重新生成，删除整条规则会连同历史实例一并删除。暂时搁置保留记录。
- 自动推荐的时间和精力分开：总分钟不超预算，高消耗任务占比随状态调整（差 25%、一般 60%、好 100%）。未来精力暂按一般估计；手动安排可自选任务、份额、顺序，超预算提醒但允许保存。
- 推荐考虑截止紧迫、计划日期、阶段目标、未来周期实例和剩余工作量；长期任务可拆成每日份额，无日期任务长期未推进时提高参与机会。
- 推荐只是估计，不承诺必然赶上 DDL。超出容量显示风险，不悄悄超额排任务。
- 完成今日份额不等于整个任务完成；记录投入会扣减剩余估计，允许单独修正估计。
- 持久化今日计划，不因刷新、完成任务自动重排；自动重排遵守当天预算；手动修改保留已投入时间、已完成和跳过的份额。
- 任务版本 + 全局数据修订号防旧页面覆盖，事务保证计划和任务记录一致。

## 技术选择
Python + Flask + SQLite + 原生 HTML/CSS/JS。生产 Gunicorn，反向代理 HTTPS。
无前端构建环节，减少服务器内存与维护负担。算法独立模块。

## 暂缓
自定义周期间隔、周视图、能量学习、晚间问卷、娱乐恢复、AI、PWA/离线同步、推送、邮箱找回密码和管理员后台。
